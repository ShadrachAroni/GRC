# Automation Layer

This directory holds the automation scripts and background workers for the SecureBank GRC Platform.

## Scheduled Tasks & Scripts
- `mfa_checker.py`: Validates compliance with Multi-Factor Authentication settings.
- `capa_assigner.py`: Automates assignment of Corrective and Preventive Actions (CAPAs) based on audit gaps.
- `vendor_scorer.py`: Calculates quantitative security risk scores for vendors.
